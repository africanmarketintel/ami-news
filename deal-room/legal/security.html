1. How we protect information

This page describes controls in place for the Deal Room. Each statement must be confirmed by ABTA’s developer before publication.

  • All connections to the website and its services use encrypted HTTPS.
  • Uploaded documents are stored in a private storage area. Files are available only through short-lived links issued after a membership check.
  • Membership is checked on the server for every request that reveals or changes confidential data.
  • Counterparty identities are released only after ABTA has issued an Introduction Notice.
  • PDF documents shared with members are watermarked with the viewer’s details.
  • Key actions, including agreement acceptance and document access, are recorded in an audit log.
  • Payments are processed by Stripe. ABTA does not see or store card details.

2. Reporting a security issue

If you think you have found a security issue, email ami@abta.africa with “Security” in the subject line. Do not include confidential information in your first message.
